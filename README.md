# Komari 监控

当前版本：v1.1.0

Komari 监控是一款面向 AstrBot 的节点状态插件。它会从 Komari 站点读取节点运行数据，并生成清晰的粉色监控卡片；节点状态或资源占用发生异常时，也可以自动向指定会话发送图片提醒。

## 功能

- 以图片展示节点在线状态、CPU、内存、磁盘、Swap 和运行时长。
- 支持 Komari 公开接口，也支持通过 Token 访问需要鉴权的站点。
- 后台定时检查节点状态，离线和恢复在线分别发送一次节点信息图片。
- 支持 CPU 与内存高占用预警，每次进入高占用状态时提醒一次。
- 支持在每天指定时间自动推送所有节点的状态图片。
- 支持多个提醒会话，可按 AstrBot 的 UMO（统一消息来源）填写。
- 兼容 Windows、Linux 和 macOS，并针对不同系统提供中文字体候选。
- 监控图片与状态记录保存在 AstrBot 的插件数据目录中，不写入插件代码目录；图片使用唯一文件名并自动清理，避免平台缓存显示旧图。

## 配置

配置页面按用途分为五个区块，常用设置集中在前四项，高级参数通常无需修改。

### 站点连接

| 配置项 | 说明 |
| --- | --- |
| 站点地址 | Komari 站点地址，例如 `https://monitor.example.com`。不要填写末尾斜杠。 |
| API Token | 可选。站点需要鉴权时填写；留空则使用公开接口。 |

### 提醒会话

| 配置项 | 说明 |
| --- | --- |
| 主动提醒总开关 | 关闭后不会发送异常提醒和每日状态图。 |
| 提醒目标会话 | 接收消息的 UMO 会话列表，每行一个；所有主动推送共用此列表。 |

### 异常预警

| 配置项 | 说明 |
| --- | --- |
| 节点状态提醒 | 节点离线与恢复在线时各提醒一次。 |
| CPU 高占用提醒 | CPU 占用达到设定阈值时提醒一次。 |
| CPU 告警阈值 | CPU 高占用的判定百分比。 |
| 内存高占用提醒 | 内存占用达到设定阈值时提醒一次。 |
| 内存告警阈值 | 内存高占用的判定百分比。 |

### 每日状态推送

| 配置项 | 说明 |
| --- | --- |
| 每日推送开关 | 每天向提醒目标推送一次所有节点状态图。 |
| 推送时间 | 使用 AstrBot 所在系统的本地时间，格式为 `HH:MM`。 |

### 检查与缓存

| 配置项 | 说明 |
| --- | --- |
| 检查间隔 | 后台检查间隔，单位为秒，默认和最小值均为 30。 |
| 数据缓存时间 | Komari 状态数据的短时内存缓存时间，单位为秒。 |

配置保存后重载插件即可生效。

## 使用

插件仅提供一个指令：

```text
/komari
```

发送后会返回当前 Komari 节点状态图片。如果站点暂时不可用，插件会返回简明的错误提示，不会影响 AstrBot 其他功能。

## 自动提醒

插件第一次成功检查时只建立当前状态，不会发送提醒。后续发现节点离线、恢复在线、CPU 高占用或内存高占用时，会发送包含节点当前信息的粉色提醒图片。相同状态持续期间不会重复发送；发送失败的提醒会保留 24 小时并在后续检查中重试，多个目标会分别记录成功状态。资源占用回落至告警阈值以下时仅在后台静默重置，之后再次达到告警阈值时才会重新提醒。状态记录会持久化保存，插件重载后仍然保持去重效果。

启用每日状态推送后，插件会在每天设定时间之后的首次检查中发送一次与 `/komari` 相同样式的所有节点状态图。异常提醒与每日状态推送均复用提醒目标会话。插件只在发送成功后记录“日期 + 配置时间”；发送失败会在后续检查中重试，同一天修改推送时间后会按新时间重新发送。

## 日志与故障处理

插件按严重程度记录运行信息，且不会在日志中输出 Komari Token：

- `DEBUG`：轮询、缓存命中、渲染完成与消息发送等诊断信息。
- `INFO`：插件启动、异常状态触发与每日推送结果。
- `WARNING`：配置值无效、站点暂时不可用或接口数据格式异常等可恢复问题。
- `ERROR`：状态文件读写、图片生成或消息发送失败，并保留异常堆栈便于排查。

外部接口异常不会中断 AstrBot。状态文件缺失或损坏时，插件会重新建立监控基线，避免因历史状态不可用而连续发送提醒；图片生成失败时，`/komari` 会返回可读提示。
